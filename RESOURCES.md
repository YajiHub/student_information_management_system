# Enterprise REST API & NestJS Architecture Resources

## Knowledge

- [NestJS Official Documentation](https://docs.nestjs.com/)
  Primary architectural guide for NestJS dependency injection, controllers, guards, interceptors, and exception filters. Use for: standard request lifecycle and decorator patterns.
- [Prisma ORM Documentation](https://www.prisma.io/docs)
  High-productivity, type-safe database toolkit for PostgreSQL. Use for: schema modeling, relations, composite keys, migrations, and query execution.
- [Microsoft REST API Guidelines](https://github.com/microsoft/api-guidelines)
  Enterprise REST standards for uniform URL naming, status codes, error representation, and pagination query schemas. Use for: designing predictable RESTful interfaces.
- [OWASP Top 10 API Security Risks](https://owasp.org/www-project-api-security/)
  Authoritative guidance on modern API vulnerabilities, specifically Broken Object Level Authorization (BOLA/IDOR). Use for: implementing object-level access guards.

## Wisdom (Communities)

- [r/nestjs](https://www.reddit.com/r/nestjs/)
  Active Reddit community for NestJS architecture patterns, middleware best practices, and performance tuning.
- [NestJS Official Discord Community](https://discord.gg/nestjs)
  Real-time help channel for architectural validation, community libraries, and troubleshooting framework nuances.
- [Prisma Discord Community](https://discord.gg/prisma)
  High-signal community for complex relational queries, schema optimization, and migration strategies.
