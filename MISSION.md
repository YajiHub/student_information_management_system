# Mission: Enterprise RESTful API Development for Student Information Management Systems

## Why
Master enterprise-grade backend development using NestJS, TypeScript, and Prisma with PostgreSQL to excel in BSIT 4th Year coursework (Special Topics Laboratory Activities 2 & 3) and build competitive full-stack software engineering capabilities for post-graduation industry roles.

## Success looks like
- Design and implement a robust, production-ready RESTful API conforming to strict REST standards and academic specifications.
- Model real-world institutional complexities, notably irregular student handling, credit unit capping, and cross-section scheduling.
- Enforce strict security through JWT authentication, Role-Based Access Control (RBAC), and Object-Level Authorization preventing Insecure Direct Object References (IDOR).
- Build automated E2E test suites with 100% pass rates and provide comprehensive OpenAPI and Postman documentation for seamless frontend consumption.

## Constraints
- Windows development environment using PowerShell and local PostgreSQL 18.
- Laboratory Activity 2 grading rubric compliance (standard JSON envelopes, minimum seed data thresholds, 20 mandatory acceptance demonstration cases).
- Direct preparation for Laboratory Activity 3 (Frontend Framework consumption).

## Out of scope
- Third-party OAuth2 social logins (Google, GitHub) for institutional academic records.
- Microservices deployment (monolithic modular architecture is required).
